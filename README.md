# 🚀 Discord Promo Link
This tool allows you to link Streamlabs promos to tokens for redeeming.  

### **Key Features**:
- 🌐 **Proxy Option**: You can input proxies into `proxies.txt`, or by default, it will use none.  
- 🔧 **Bug Support**: If you run into any issues, feel free to reach out, and I'll help you fix them.  
- ⚡ **Customizable Threads**: Adjust the number of threads for optimal performance.  
- 📂 **Optional New Output Folder**: Choose to create a fresh folder for each session or keep all outputs in one place.  
- 🔧 **Bug Support**: If you run into any issues, feel free to reach out and I'll help you fix them.


### **How to Use**:
1. **Download and Install Python**:  
   Visit [https://www.python.org/downloads/](https://www.python.org/downloads/) and install Python version 3.13.1 or higher.

2. **Set Up the Environment**:  
   Open a command prompt (CMD) in the folder where the scraper is located.

3. **Install Dependencies**:  
   Run the following command to install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Program**:  
   Once the dependencies are installed, run the program with:
   ```bash
   py main.py
   ```
